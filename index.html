Overview

The Editor version in the workshop project was 6000.0.26f1 (ccb7c73d2c02). The handwritten gameplay is CharacterController.cs and NewMonoBehaviourScript.cs. Both read Input.GetAxis and write transform.position. Unity Learning.txt covers Awake, Start, Update, LateUpdate, FixedUpdate, render pipelines, and Rift versus Quest. Several of those sentences do not match Unity's behaviour. The learning pages quote them and then correct them.

SampleScene is the template camera and light. The small vrscene (39,578 bytes) is an XR sandbox. A later file, VRScene-imported.unity (3,541,156 bytes, a different GUID), is the city layout: wall segments, gates, terrain, Starter Assets player prefabs, and a disabled copy of the movement script on a character mesh that is not in this tree. Both files are under workshop-evidence, outside Assets. This project does not play them.

Courtyard Walk is the runnable scene. It is a walled yard of cubes, a capsule, five spheres, and a red pad. The same ground rules are drawn on this page in JavaScript so they can be read without the Editor. That canvas is not a Unity build.

Learning outcomes that the files support

  • I can point at Awake on the bootstrap, Update on the walker, and LateUpdate on the camera, and I can say why FixedUpdate is absent. Evidence: player loop.
  • I can show the original axis test and explain why it does not gate movement. Evidence: movement.
  • I can explain why transform.position walks through walls and CharacterController.Move does not. Evidence: collision.
  • I can name built-in, URP, HDRP, and the Scriptable Render Pipeline without calling URP a low-quality mode. Evidence: pipelines. The workshop project used URP. This demo uses built-in on purpose.
  • I can describe the Rift and Quest notes without claiming I shipped a VR game. Evidence: XR context.

Architecture

  1. CourtyardWalk.unity contains the directional light, the main camera, and one CourtyardBootstrap.
  2. On Play, Awake looks for CourtyardRoot. If it is missing, CourtyardBuild.Create builds the yard.
  3. The builder parents a ground cube, four wall cubes, four obstacle cubes, one cylinder, five trigger spheres, a trigger pad, and a capsule.
  4. The capsule's primitive collider is removed and a CharacterController plus Walker are added. Walker is not named CharacterController, so it does not hide the engine type.
  5. CourtyardSession counts orbs and handles R. CourtyardHud draws IMGUI text. FollowCamera runs in LateUpdate.
  6. The editor menu Workshop/Build Courtyard Walk Scene calls the same Create and saves the scene. Play does not need that menu.

Numbers shared with the canvas live in CourtyardLayout: half-extent 12, wall thickness 0.5, player radius 0.5, speed 5, five orb positions, four blocks, one column, and the pad at (8, 0.75, -8).
