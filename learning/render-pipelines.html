Render pipelines

Three names, and the framework under two of them

The note says the total number of pipelines is three and then lists four: built-in, Universal, Scriptable, and High Definition. It also says pipelines are for performance and graphics, and that in "dev ops" they transmit data. In this Unity project the word means the render pipeline.

  • Built-in render pipeline. The older pipeline. Courtyard Walk uses it. GraphicsSettings has no custom pipeline asset.
  • Universal Render Pipeline (URP). A Scriptable Render Pipeline aimed at a wide range of hardware. It is not a "low quality only" mode. The workshop project used URP 17.0.3 because Starter Assets asked for it.
  • High Definition Render Pipeline (HDRP). A Scriptable Render Pipeline aimed at higher-fidelity lighting on stronger machines. The workshop project did not use it.
  • Scriptable Render Pipeline (SRP). The framework URP and HDRP are built on. It is not a fourth quality slider beside them.

Switching this demo to built-in is a publishing choice: the scene then has no dependency on the Starter Assets package or on URP assets that we are not allowed to assume we can redistribute. It is not a claim that the workshop Editor project was built-in. It was URP.
