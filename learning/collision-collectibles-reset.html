Collision, collectibles, and reset

Rules the scripts implement

  • Writing transform.position teleports the object. Colliders do not stop it. Walker calls CharacterController.Move, so the wall cubes and the obstacle cubes block the capsule.
  • Orbs are spheres with trigger colliders and kinematic rigidbodies. Unity sends OnTriggerEnter when a CharacterController meets a trigger only if one side has a Rigidbody. The orb has that Rigidbody and does not use gravity.
  • CollectibleOrb disables itself and tells CourtyardSession. At five orbs the status becomes Courtyard clear.
  • The red pad is also a trigger. It calls ReturnToSpawn and leaves the collected count alone.
  • R calls Restart: count returns to zero, orbs are activated, and the walker returns to (0, 1, -8).
  • If the capsule falls below y = -4, it is returned to the spawn. The ground cube should make that rare.

The HUD is OnGUI. It does not need a Canvas, a font file, or TextMeshPro. The text scales with screen height so a 1080p game view stays readable.

The browser illustration follows the ground-plane part of these rules and says so on the page. It does not simulate gravity.
