Open, play, and build

Setup

Courtyard Walk is source for the Unity Editor. The .cs files do not start a game by themselves, and this website is not the Unity player. A check of this environment found no Unity Editor binary and no Unity license file, so import, Play, and build were not run.

To play it you need a 64-bit desktop that Unity Hub supports, with Editor 6000.0.26f1 installed and a normal Unity license. The scene uses primitive meshes, one directional light, and the built-in render pipeline. It does not need a headset, a high-end GPU, or Starter Assets. A player you build later also needs that Editor (or a player you already built on such a machine). This folder does not contain a player.

  1. Install Unity Hub and Editor 6000.0.26f1 (revision ccb7c73d2c02). A nearby 6000.0 patch may open the project and then ask to change the version. That change is yours to accept or refuse.
  2. Add the folder that contains Assets, Packages, and ProjectSettings. Do not add a nested copy of an old workshop folder.
  3. Let the Editor create Library. That folder is generated. It is gitignored.
  4. Open Assets/Scenes/CourtyardWalk.unity.
  5. Confirm Player Settings, Active Input Handling, is Input Manager (Old). The project file already sets activeInputHandler: 0.
  6. Press Play. CourtyardBootstrap builds the yard. WASD or the arrows walk. R restarts.

Optional: menu Workshop/Build Courtyard Walk Scene writes the primitives into the scene so they show in the Hierarchy before Play. Play already works without it.

The manifest lists only built-in modules. If the Editor offers to add URP, the Input System, Cinemachine, or XR, the courtyard does not need them. Adding them will not by itself recreate Starter Assets.

Controls

  • A D and arrows left right: Horizontal.
  • W S and arrows up down: Vertical. Up is positive Z, into the yard from the southern spawn.
  • Walls and blocks block movement. Orbs are triggers. The red pad returns the walker to the spawn and keeps the score.
  • R restarts the walk and restores orbs.

Player build

File, Build Profiles, choose the desktop target, and build to a folder outside this tree. EditorBuildSettings enables only CourtyardWalk.unity. No player, no Build directory, and no WebGL files are included. Do not add a website button that points at a build that is not there.

The old repository contained builds/workshop.exe. That player was the workshop upload, with Starter Assets and XR plugins inside it. It is not part of this tree and it is not required to read or to rebuild Courtyard Walk.
